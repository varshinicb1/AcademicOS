Production secrets

Keys and settings for the live AcademicOS service. Fill in only what you have; leave the rest blank and add it later.

This page never sends anything. It runs only in your browser and cannot make a network request. Nothing you type is saved, logged or uploaded. It builds a script for your own Google Cloud login; the script stores each value in Google Secret Manager and gives the running service access. Run it once and it deletes itself.

Where it goes

Your script

It contains your values (encoded, not hidden). Save it, run it once, and it removes itself. Do not send or commit it.

  1. Open a terminal and sign in once: gcloud auth login
  2. Windows: powershell -ExecutionPolicy Bypass -File .\apply-secrets.ps1
    Mac or Linux: bash apply-secrets.sh
  3. It ends by updating the live service, which starts a new revision and checks it is healthy.
