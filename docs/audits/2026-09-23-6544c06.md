## 4. Defects, most serious first

**D1 — The live web app throws when a teacher reopens a paper it just made.**
`frontend/lib/domain/repositories/requests.dart:160` (at 6544c06) — `PaperMetadata` declares
`required String schoolName` at the deployed commit. The deployed server returns
`metadata.schoolName: null`:
```
POST /api/v1/papers/quick-generate {"subject":"Science","grade":10,"totalMarks":80}
  -> 200, metadata.schoolName = None
POST /api/v1/papers/generate-from-template {"templateId":"preset:cbse:10:science:annual","allowGaps":true}
  -> 200, paper.metadata.schoolName = None
```
The paper builder survives only because `paper_builder_api.dart:parsePaper` patches
`meta['schoolName'] ??= ''` before parsing. **Every other path parses the same bytes
through `GeneratedPaper.fromJson`** — `api_client.dart:91, 107, 114, 125, 130` — and
throws `type 'Null' is not a subtype of type 'String'`. That is the assessment
list/detail screen, i.e. "open the paper you made yesterday".
The live bundle is the unfixed one: its `PaperMetadata.toString` prints
`"PaperMetadata(assessmentTitle: "+s.a+", schoolName: "+s.b+", subject: "+s.c+…`,
the pre-fix field order, and its decode site is `m=A.a2(o.h(q,"schoolName"))`, a
non-null cast. The fix exists **uncommitted** in the working tree. Reproduce:
generate a paper, then open it from the assessment list on vidyuthlabs.web.app.

**D2 — The client truncates the competency target to zero.**
`frontend/lib/domain/entities/enums.dart:600` and

`src/academicos/corpus/ncert_exemplar.py:2327`:

def _difficulty_for(marks: int) -> str:
    return "easy" if marks <= 2 else "medium" if marks <= 3 else "hard"
```

```
Mathematics 9 {1:{easy:140}, 2:{easy:61}, 3:{medium:41}, 4:{hard:15}, 5:{hard:25}, 6:{hard:6}, 7:{hard:2}}
Science 10   {1:{easy:312}, 2:{easy:3}, 3:{medium:127}, 5:{hard:51}, …}

which the bank ever carries — hence 0.0–15.8% CBQ on all 10 papers against a 50%
target. The guard that should have caught this exists: `selection.py:78` returns
`None` when `metadata.difficultyInferred` is set, and the exemplar path never sets

Reproduce: `POST /papers/quick-generate {"subject":"Mathematics","grade":9,

**D4 — Superscripts collapse into digits in a Maths paper.**
