1. **No signed-in flow on either surface went through registration.** The previous
   audit minted a principal and a teacher locally through `/auth/register`. I did not,
   because this brief forbids creating accounts. Item 2.1's bootstrap → invite →
   sign-in chain therefore rests on the suite (the cited full gate, plus
   `test_role_gates.py` and `test_frontend_backend_contract.py`, which I re-ran). I did
   not drive it myself.
2. **PDF glyphs were checked in DejaVu Sans**, taken from matplotlib's copy
   (`…\Python312\…\mpl-data\fonts\ttf\DejaVuSans.ttf`), by setting
   `pdf._FONT_CANDIDATES` before any render. That is the production font family
   (`pdf.py:64-66`), but not the container's own file.
3. **The full test suites were not run by me.** I cite `pytest_3197f4e_venv.log`
   (`3611 passed, 113 skipped, 8 xfailed in 1125.94s`, 0 failures). That log carries no
   commit stamp, so it is attributed to `3197f4e` by the brief and not by the file. I
   re-ran **11 Python test files**, in three sequential batches, with the venv Python:
   **381 passed, 2 skipped, 6 xfailed, 0 failed**. I also ran one `flutter analyze`:
   **7 info-level issues**, the same seven as last audit.
4. **The working tree was left exactly as I found it.** The same 7 generated
   plugin-registrant files were modified before I arrived. `git status --short` hashed
   `85ff3c70…` before and after. `find -newer` over the worktree (excluding `.git`,

**D23: Returning browsers run a stale app, and every deploy since 22 Sep is invisible to them.** *(New finding. Pre-existing config, not a regression.)*
`firebase.json:27-28` sets `Cache-Control: public, max-age=31536000, immutable` on
`**/*.@(js|…)`. That rule covers `flutter_bootstrap.js` and `main.dart.js`, whose names
carry no content hash. `/` is `max-age=3600`, so index.html refreshes, but it asks for
`flutter_bootstrap.js` by the same name, and the browser serves its cached copy without
asking the server. Measured in a real browser today:
`performance.getEntriesByType('resource')` shows `transferSize 0` for both files.
`fetch('/main.dart.js')` returns 5,450,798 bytes, `Last-Modified 22 Sep 14:48:18 GMT`,
cached 22 Sep 14:50. That bundle has no `/assessment/build`, no "Time saved", no
"Book editions" and no `[6,7,8,9,10]` builder list. It has the old "1-Click Quick
Paper" dialog offering Grade 11 and 12. Its cached bootstrap carries
`serviceWorkerVersion 923529901` against the live `2459031148`. A browser that first
loaded the app before the builder shipped has never been shown the builder, unless its
user hard-reloads (Ctrl+Shift+R) or the cache is evicted. A normal reload does not
revalidate `immutable` subresources. It also undercuts the scope rule
"never offer what we cannot serve", and every hand-deploy check that reads
`main.dart.js` with curl.
*Reproduce:* `curl -sI https://vidyuthlabs.web.app/main.dart.js | grep -i cache-control`.
Then, in any browser that visited before 23 Sep 20:08 GMT, compare
`(await fetch('/main.dart.js')).text()).length` with the same call using
`{cache:'no-store'}`.
