## 3. Defects, most serious first

**D1 — 1,248 served questions (38%) print an answer key with no marks on any value point; 345 more (10.5%) have no value points at all.**
`academicos-data/syllabus/questions.json` — each record's `answerScheme.markingPoints[].marks`.
Reproduce:
```
PYTHONPATH=…/src …/python.exe -c "
import json;items=json.load(open('academicos-data/syllabus/questions.json',encoding='utf-8'))['questions']
z=[q for q in items if (q.get('answerScheme') or {}).get('markingPoints') and sum((m.get('marks') or 0) for m in q['answerScheme']['markingPoints'])==0]
print(len(z),'of',len(items))"
```
→ `1248 of 3286`. Visible to a teacher: generate a Science-10 paper, `POST /papers/{id}/export/answer-key`, `GET /papers/{id}/file?format=answer-key` — the marking scheme prints `- Plants raised by vegetative propagation can bear flowers [0m]`. Q1's "Expected answer" column is a truncated concatenation of the MCQ options, not the answer. The same defect is served by `/v1/questions/{id}/scheme` (verified: `"marks": 0` on both points of `cbse:q:src:11f9b943f602a1077a1abe9d:12`). **A marking scheme that allocates no marks is not usable by the person marking.**

**D2 — Grades 6, 7, 8, 9 and 11 cannot get a paper at all.**
Live: `GET /api/v1/catalog` → only grades 10 and 12, 3,286 questions.
Reproduce: `POST /api/v1/papers/quick-generate {"subject":"Science","grade":8,"totalMarks":80}` → **400** `"Unable to find sufficient questions for Science Grade 8 in the question bank."` Same for 6, 7, 9, and Physics 11. Meanwhile `paper_builder_controller.dart:20` offers `builderGrades = [6,7,8,9,10,11,12]` in the UI, so a teacher picks a class the product cannot serve and hits a 400 at the last step. Fixed by the bank rebuild — **not in this deploy**.

**D3 — The project's own "no silent failures" guard fails at the deployed commit, with 12 of 13 violations in the guided paper builder.**
`flutter test test/no_swallowed_errors_test.dart` → fails on:
`lib/presentation/paper_builder/paper_builder_controller.dart:219, 290, 303, 375, 463, 501, 548, 575, 613`; `widgets/bank_picker.dart:73`; `widgets/section_editor.dart:128`; `widgets/template_step.dart:173`; `assessment/pages/assessment_review_page.dart:332`.
The cause: the builder uses `apiErrorMessage` (`lib/data/datasources/api/paper_builder_api.dart:30`) instead of the canonical `serverErrorMessage` (`lib/data/datasources/api/api_error.dart:37`). It is not *silent* — it does surface the server's `detail` and does separate a connection error — but it has **no 401/403/404 branch**, so an expired session in the paper builder reads "The server answered 401. Try again." instead of "You're signed out — sign in again", and a 403 reads "The server answered 403. Try again." `git diff cb16658 ba42d49 -- frontend/lib/presentation/paper_builder/` is empty, so this is exactly what is live.

**D4 — The product's own school-setup path builds a year plan with zero lessons and reports complete success.**
`POST /curriculum/seed/cbse10` creates units and chapters but no topics or subtopics (`src/academicos/curriculum/seed_cbse10.py:10` says so). Then:
`POST /curriculum/books/{id}/schedule?academic_year_id=…` → **200** with
`"lessonsCreated":0, "subtopicsScheduled":0, "subtopicsUnscheduled":[], "allSubtopicsScheduled":true, "warning":null`.
Root cause: `src/academicos/curriculum/scheduling.py:94` — `all_subtopics_scheduled` is `self.warning is None`, and `_shortfall_warning` is built from subtopic counts, so with zero subtopics it is vacuously true. A principal who follows the product's own seed path gets an empty year plan and an API that says everything is scheduled. (`teaching-time-estimates` does warn, via `unitsSkippedNoSubtopics` listing all 7 units — but the schedule route, the one that matters, does not.)

**D5 — "Parallel" sets are largely the same paper.**
`POST /papers/quick-generate {"subject":"Science","grade":10,"totalMarks":80,"setCount":3}` → sets A, B, C, 80 marks each. **A vs B share 32 of 38 questions; A vs C share 38 of 38** — set C is set A in a different order. On a bank this thin, handing out three "parallel" sets does not stop copying. Symptom of D2/thin bank, but it ships as a feature.

**D6 — The five 375 px overflow fixes are not in the live build.**
`git ls-tree cb16658 -- frontend/test/responsive` is empty; the suite and the fixes are in `ba42d49`, one commit past the deploy. So on a phone browser the live build still runs "Parallel Question Sets (2 Sets)" 156 px off its card, the coverage dashboard's "Academic Year Progress / As of <date>" 211 px off, a delayed lesson 15 px short, and the drawer button — the only route to navigation on a phone — at 40 px against a 44 px minimum. **D7 — Time saved is computed correctly and shown to nobody.**
`GET /api/v1/paper-timing` returns measured generation seconds with a declared baseline and an honest caveat, and is principal-gated. Grep of the entire Flutter client for `paper-timing`, `paperTiming`, `timeSaved`, `minutesSaved` → **zero hits**. Scorecard items 5.2 and 6.3 both depend on it. Likewise `/api/v1/catalog` is the whole of item 5.4 and appears in no principal screen. Two items' worth of working backend, one screen away from counting.

**D8 — First-load payload is too big for the 2.4 bar.**
`main.dart.js` 1,137,575 B gzipped plus a CanvasKit/skwasm wasm of 1.2–2.3 MB ≈ 2.4–3.5 MB transferred on a cold visit. At a throttled-4G ~200 KB/s that is 12–17 s of download before the first frame, against item 2.4's < 10 s.

**D9 — Unknown request fields are accepted silently.**
`POST /papers/quick-generate {"subject":"Science","grade":10,"totalMarks":80,"parallelSets":5,"zzz":1}` → **200** with zero sets. The real field is `setCount`. A client that sends the wrong name gets a plausible-looking paper instead of a 422. (This is how I first mis-measured item 1.4.)

**D10 — `flutter analyze` is not clean: 61 issues, 20 warning-level.** Item 8.2 requires clean. Includes `invalid_null_aware_operator` at `lib/data/repositories/repositories_impl.dart:74-75` and 8 unused fields in `lib/core/theme/app_theme.dart`.

**D11 — `/papers/generate` is the one generation route with no timing instrumentation** (`src/academicos/assessment/routes.py:340`; the other three call `time.perf_counter()`).

**D12 — 96 of 3,286 served questions (2.9%) cannot be answered as served:** 52 reference a figure/diagram/graph/map with no asset id, 35 MCQ/assertion-reason carry no options, 6 reference a table with no asset, 3 reference a passage the stem does not contain.
